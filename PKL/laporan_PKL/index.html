            Lampiran 2

            Jurnal Harian

            Klik Buat Tanggal Otomatis untuk membuat satu baris per hari kerja dari tanggal PKL, lalu isi kegiatannya. Bisa juga isi lewat Excel / Google Sheets lalu impor file CSV.

            Cara mengisi lewat Excel / Google Sheets

            1. Klik Unduh Contoh CSV, lalu buka di Excel atau impor ke Google Sheets.

            2. Isi satu hari per baris. Jangan ubah judul kolom: tanggal, kegiatan, kompetensi, output, validasi.

            3. Simpan sebagai CSV — di Excel: File → Save As → CSV UTF-8 (Comma delimited); di Google Sheets: File → Download → CSV.

            4. Klik Impor dari CSV dan pilih file tersebut. Tanggal seperti 01/07/2026 otomatis menjadi Rabu, 01 Juli 2026.
